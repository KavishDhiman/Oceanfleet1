# 🌊 OceanFleetApp

## 🚢 Project Overview

**OceanFleetApp** is a Java-based console application designed to simulate a real-world vessel performance tracking system.  
The project demonstrates core **Object-Oriented Programming (OOP)** principles and effective usage of the **Java Collections Framework** through practical implementation.

The application enables users to manage vessel records, analyze vessel performance, and retrieve vessel information efficiently using a clean and modular architecture.

---

# 🎯 Objectives

The primary goals of this project are to:

- Store and manage vessel performance details
- Retrieve vessel information using Vessel ID
- Identify high-performance vessels based on speed metrics
- Demonstrate real-world implementation of Java OOP concepts
- Utilize Java Collections for efficient data handling
- Maintain clean, scalable, and modular code architecture
